# AI Engineer Portfolio

This repository contains my practice projects in Artificial Intelligence and Machine Learning.  
It documents my progress as I strengthen my skills in Python, Machine Learning, Deep Learning, and Data Analysis.

## 📂 Structure
- `notebooks/` → Jupyter notebooks for practice and projects
- `datasets/` → Sample datasets used for experiments
- `models/` → Python scripts for reusable models
- `results/` → Accuracy reports, plots, and evaluation metrics

## 🚀 Topics Covered
- Python basics (NumPy, Pandas, Matplotlib)
- Machine Learning (scikit-learn: regression, classification, decision trees)
- Deep Learning (PyTorch & TensorFlow feedforward networks, CNNs)
- Data preprocessing (cleaning, scaling, encoding)
- End-to-end projects with real datasets
